# MUSICWORLD MVP

A mobile-first clickable prototype for MUSICWORLD — “A World of Artists. A Standard of Music.”

## Run locally
1. Install Node.js.
2. Open this folder in a terminal.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local Vite address shown in the terminal.

## Current prototype
- Home
- Global Top 10
- Rising Artists
- Discover by continent
- Charts and chart filters
- AI Music section
- Library
- Profile
- Bottom navigation
- Basic music-player overlay

This is a UI prototype. Real streaming, artist accounts, uploads, licensing, database, authentication, chart calculations, anti-fraud systems and payments still need to be implemented before production launch.
